# SiteWeb-Gratuit

Ce dépôt contient un site vitrine moderne et prêt à être publié pour un hébergement web gratuit.

## Ce qui est inclus

- `index.html` : structure principale de la page d’accueil
- `styles.css` : design complet, responsive et moderne
- `script.js` : interactions légères et gestion de l’année dynamique
- `favicon.svg` : icône du projet

## Objectif du projet

Créer un site d’accueil professionnel et lisible, adapté à une présence web simple, rapide et accessible sans coûts de démarrage importants.

## Utilisation locale

1. Ouvrez le fichier `index.html` dans votre navigateur pour voir le rendu.
2. Modifiez les textes, couleurs et sections selon votre projet.
3. Publiez le site sur GitHub Pages ou sur un hébergeur gratuit de votre choix.

## Publication sur GitHub Pages

1. Ouvrez le dépôt GitHub.
2. Allez dans `Settings`.
3. Choisissez `Pages`.
4. Sélectionnez `Deploy from a branch`.
5. Branche : `main`
6. Dossier : `/` (racine)
7. Cliquez sur `Save`.
8. Attendez la génération de la page.

## Personnalisation rapide

Dans `index.html`, vous pouvez modifier :
- le titre du site
- le slogan de la page d’accueil
- les sections de services, offres et FAQ
- les coordonnées de contact
- le message du formulaire de contact

## Idée d’évolution

Le projet peut ensuite être transformé en :
- portfolio
- site vitrine pour une activité
- landing page pour un service
- site pour une boutique ou une offre de prestations
