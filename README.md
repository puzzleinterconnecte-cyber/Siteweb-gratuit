# SiteWeb-Gratuit

Ce dépôt contient un site vitrine moderne et prêt à être publié, conçu pour un hébergement gratuit.

## Contenu

- `index.html` : page d'accueil principale
- `styles.css` : styles visuels de l'interface
- `script.js` : scripts légers (année dynamique)

## Utilisation

1. Ouvrez `index.html` dans votre navigateur pour visualiser le site.
2. Personnalisez les textes, couleurs et sections selon votre projet.
3. Publiez-le sur GitHub Pages ou sur tout autre hébergeur gratuit.

## GitHub Pages

Pour publier sur GitHub Pages :
1. Allez sur votre dépôt GitHub.
2. Ouvrez l'onglet `Settings`.
3. Sélectionnez `Pages`.
4. Choisissez la branche `main` et le dossier racine `/`.
5. Enregistrez et attendez la génération du site.

## Personnalisation rapide

Modifiez les informations dans `index.html` pour changer :
- le titre du site
- le texte de présentation
- les coordonnées de contact
- les sections de services et tarifs
